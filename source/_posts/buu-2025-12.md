```php
class emmm
    {

            $whitelist = ["source"=>"source.php","hint"=>"hint.php"];
```
定义类：emmm
静态方法:checkFile
    作用：检查要包含的文件是否在白名单中
    白名单是一个关联数组$whitelist，其中包含了允许包含的文件的键值对。在代码中，允许包含的文件有"source"=>"source.php"和"hint"=>"hint.php"。

```php
if (! isset($page) || !is_string($page)) {
                echo "you can't see it";
                return false;
            }
```
isset:检查是否存在$page参数
is_string:检查传入的$page参数是否为字符串类型

```PHP
 if (in_array($page, $whitelist)) {
                return true;
            }
```
in_array：检查是否在$whitelist中找到传入的 $page

```PHP
 $_page = mb_substr(
                $page,
                0,
                mb_strpos($page . '?', '?')
            );
```
mb_substr：从起始位置开始截取到mb_strpos($page . '?', '?')
mb_strpos:查找字符串$page . '?'中第一个问号 `?` 的位置
    先在 `$page` 末尾拼接一个问号 `?`,再找`?`的位置
总之就是：从字符串 `$page` 中提取问号 `?` 之前的部分

```php
if (in_array($_page, $whitelist)) {  
                return true;  
            }          $_page = urldecode($page);

```
URL编码，之后再次检查传入的$page是否直接在白名单中存在
